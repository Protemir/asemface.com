# asemface.com

Әсем Жол, the racing game that lived here, moved to [gamemetric.dev/asem/](https://gamemetric.dev/asem/) on 15 October 2026, next to the other games. Its code is now in the [gamemetric.dev](https://github.com/Protemir/gamemetric.dev) repository, folder `asem/`; the history up to the move stays in this repository.

The site is a forwarding page: every address on asemface.com opens the game on gamemetric.dev with the same query (so `?group=` invite links keep working), and the saves of the player's browser go along in the address, so nobody loses their chapters, garage or records.
